# Política de privacidad de MagicPDF

MagicPDF abre y procesa tus PDF en tu equipo, incluido el reconocimiento de texto en español e inglés. Puedes usar el lector, el editor y el OCR sin cuenta y sin conexión a Internet. MagicPDF no envía el contenido de tus documentos a un servidor externo ni incorpora telemetría.

Para editar, la aplicación crea copias de trabajo temporales en el perfil de Windows. Tras un cierre inesperado, puede conservar copias con cambios para proteger tu trabajo. Las preferencias de la aplicación también se guardan en el equipo. Los PDF que guardas o exportas quedan en la ubicación que eliges.

La edición descargada desde GitHub consulta GitHub Releases cuando usas **Buscar actualizaciones…**. Si confirmas la descarga, obtiene el instalador desde GitHub, comprueba su SHA-256 y lo guarda donde tú elijas. La edición de Microsoft Store recibe las actualizaciones desde la tienda de acuerdo con la configuración de Windows.

Para consultas sobre privacidad, usa el repositorio de MagicPDF. Evita adjuntar PDF con información privada en los reportes públicos. [Soporte de MagicPDF](https://github.com/matfigueroac/MagicPDF/issues)
